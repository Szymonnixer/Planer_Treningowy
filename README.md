# 💪 Planer Treningowy

Prosta aplikacja mobilna na system Android, która pomaga organizować treningi poprzez losowanie ćwiczeń i kontrolowanie liczby wykonanych serii.

## 📱 O aplikacji

**Planer Treningowy** umożliwia losowanie ćwiczeń, śledzenie liczby serii dla każdego ćwiczenia oraz kontrolowanie łącznej liczby wykonanych serii podczas treningu.

Aplikacja została stworzona w języku Java z wykorzystaniem interfejsu XML.

## ✨ Funkcjonalności

- 🎲 **Losowanie ćwiczeń** – aplikacja losuje jedno z sześciu dostępnych ćwiczeń.
- 🔄 **Brak powtórzeń** – to samo ćwiczenie nie zostanie wylosowane dwa razy z rzędu.
- ➕ **Dodawanie serii** – możliwość zwiększenia licznika aktualnego ćwiczenia.
- ➖ **Odejmowanie serii** – możliwość zmniejszenia licznika, ale nie poniżej zera.
- 📊 **Łączna liczba serii** – aplikacja sumuje serie wykonane podczas treningu.
- 🔁 **Następne ćwiczenie** – zapisuje serie aktualnego ćwiczenia i losuje kolejne.
- 🧹 **Reset** – zeruje wszystkie liczniki i przywraca początkowy stan aplikacji.

## 🛠️ Technologie

- **Java** – logika aplikacji.
- **XML** – projektowanie interfejsu użytkownika.
- **Android Studio** – środowisko programistyczne.
- **Random** – losowanie ćwiczeń.

## 🚀 Jak uruchomić projekt?

1. Pobierz lub sklonuj repozytorium.
2. Otwórz projekt w Android Studio.
3. Poczekaj na synchronizację Gradle.
4. Uruchom aplikację na emulatorze lub urządzeniu z Androidem.

Celem projektu było stworzenie prostej i funkcjonalnej aplikacji mobilnej do wspomagania treningów oraz wykorzystanie podstaw języka Java, obsługi zdarzeń, zmiennych, tablic, instrukcji warunkowych i losowania danych.
